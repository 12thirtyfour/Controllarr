# Contributing to Controllarr

Welcome to Controllarr! We are an automated ROM and game library manager targeting .NET 10.

## Getting Started

Please see the README.md for an overview of the tech stack and core features.

## Issue Tracking

We use GitHub issues for bug reports and feature requests. Please use the provided templates when creating an issue.

## Pull Requests

1. Fork the repository and create your branch from `develop`.
2. Ensure your code compiles and tests pass.
3. Update documentation as necessary.
4. Fill out the pull request template completely.
